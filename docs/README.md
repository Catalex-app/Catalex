# Documentation

Catalex brings writing, previews, and local agents into one workspace. These guides explain how to use the app and how its parts work together.

- [Getting started](getting-started.md) — prepare LaTeX, open a project, and connect an agent.
- [Your workspace](workspace.md) — arrange the panes, choose themes, and use shortcuts.
- [Writing](writing.md) — edit LaTeX and Markdown, compile, and navigate previews.
- [Comments](comments.md) — leave feedback in source or preview and work through it with an agent.
- [References](references.md) — import Zotero collections and keep a project bibliography current.
- [Working with agents](agents.md) — add context, discover skills, manage conversations, and review changes.
- [Sync and recovery](sync-and-recovery.md) — use Git, connect Overleaf, rewind edits, and back up local data.

For local builds, architecture, testing, and releases, see [Developer documentation](development/README.md).
