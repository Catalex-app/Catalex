# Documentation

Catalex keeps your writing, project files, and agent work together. Start with a folder, write at your own pace, and review the changes your agent proposes.

- [Getting started](getting-started.md) — install Catalex and open your first project.
- [Writing](writing.md) — edit, compile, and leave comments.
- [Working with agents](agents.md) — connect a local agent and review its changes.
- [Sync and recovery](sync-and-recovery.md) — use Git, connect Overleaf, and rewind local edits.
- [Under the hood](under-the-hood.md) — understand where your files live and how drafts work.

For development setup, architecture, and testing, see [Contributing](../CONTRIBUTING.md).
